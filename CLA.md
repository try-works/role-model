# role-model Contributor License Agreement

The current contributor agreement version for this repository is
[cla/CLA-v1.0.md](cla/CLA-v1.0.md).

Contributors must explicitly assent to that exact version through the
repository's CLA workflow before a contribution can be merged.

Published CLA version files are immutable. Future changes must be published as
new files with new version numbers rather than editing an existing version.
