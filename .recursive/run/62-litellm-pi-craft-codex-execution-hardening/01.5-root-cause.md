## Root Cause Summary

**Root Cause:** Role Model already has the right broad execution-family split, but the shared routed-execution contract and its adjacent provider/telemetry layers froze at a thin OpenAI-compatible minimum, so Pi/Codex/LiteLLM semantics are either dropped, hardcoded, or unobservable once requests move past ingress.
**Location:** Cross-cutting boundary spanning `/role-model-router/packages/adapter-execution/src/index.ts`, `/role-model-router/packages/provider-openai/src/index.ts`, `/role-model-router/packages/provider-litellm/src/index.ts`, `/role-model-router/packages/vendor-litellm/src/index.ts`, `/role-model-router/apps/runtime-host-bridge/src/index.ts`, `/role-model-router/packages/runtime-observability/src/index.ts`, and `/role-model-router/packages/sqlite-memory/src/index.ts`
**Detailed Explanation:** Downstream clients already express the semantics this run cares about, and the runtime already owns separate LiteLLM-backed and native Codex execution families. The failure is in the middle: the common execution request cannot represent transport/session/reasoning/continuation semantics, the Responses/LiteLLM shaping layers cannot forward what the common contract never carried, the Codex family is classified by hardcoded compatibility logic instead of metadata or a single owned layer, continuation lacks a durable idempotency/side-effect receipt model, and existing telemetry surfaces persist too little semantic context to diagnose those failures at scale. The current targeted tests prove narrow ingress/routing behaviors, but they do not provide the corpus-scale or rebuilt-runtime proof needed to keep these failure families from returning.
**Fix Strategy:** Phase 2 must plan work in this order:
1. expand the shared execution contract and ingress translation boundary

3. replace scattered Codex hardcoding with capability metadata plus one explicit compatibility layer only where necessary
4. add side-effect-aware continuation/idempotency modeling on top of existing observability/persistence
5. extend the current telemetry/request-detail surfaces with the missing semantic facts
6. build deterministic corpus-scale regression harnesses before live rebuilt-runtime verification
