## Issue

The rebuilt Windows package at `role-model-router/dist/release/win32-x64` can appear stale after a successful rebuild.

## Evidence

- `role-model-router/dist/release/win32-x64/manifest.json` was written during the rebuild but reported `build_date: 2026-07-10T13:37:20+08:00`, the current commit date, not the package build time.
- `role-model-router/dist/release/win32-x64/build/client/assets/fonts/*.woff2` were freshly copied but retained upstream asset mtimes from `1985-10-26`.
- The packaged CSS in release matched the freshly built source CSS byte-for-byte and contained the expected Inter and IBM Plex Mono font declarations.
- The Windows launcher executable was freshly built and did not contain the old boot-screen strings.

## Root Cause

Release packaging derives `build_date` from git commit metadata when resolving local version information, even when `package-sea` supplies a package-time `BUILD_DATE`. Static asset copying also preserves source mtimes, so bundled third-party assets can retain intentionally old upstream timestamps.

## Fix Strategy

- Prefer explicit `BUILD_DATE` over git commit date when resolving git-derived runtime version information.
- Stamp the completed release tree to the package build timestamp after all generated artifacts have been written.
- Keep the release directory clean rebuild behavior intact.

## Verification Plan

- Add RED regression tests for explicit package build date precedence and release-tree timestamp stamping.
- Rebuild runtime UI and Windows package.
- Verify release manifest `build_date` and artifact mtimes reflect the new package build.

## Verification Result

- RED confirmed with targeted tests:
  - `runtime-version.test.ts`: explicit `BUILD_DATE` was ignored in git-derived builds.
  - `executable.test.ts`: `stampReleaseTreeModificationTimes` did not exist.

  - `corepack pnpm --filter @role-model-router/runtime-host-bridge exec vitest run test/runtime-version.test.ts test/executable.test.ts`

- Rebuilt top-level files and bundled font assets now share the package build mtime.
