## Usage Contract

1. This addendum is the active checklist for `R1` through `R8` while the run remains in Phase 5.
2. A page is not done when the code "looks close"; it is done only when:
   - it matches the Paper runtime page composition for that route
   - it uses shared design-system tokens and text styles instead of hardcoded values
   - its interactions still work in the rebuilt runtime
   - a screenshot has been captured for review
   - the user has approved the page
3. "Fixed" means implemented in the worktree and verified locally. It does not imply user approval.
4. "Remaining" is the actionable backlog for that page. Anything not empty keeps the page in `Pending` status.
