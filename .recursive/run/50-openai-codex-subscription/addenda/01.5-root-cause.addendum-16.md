- exact `chatgpt/gpt-5.4` `POST /v1/responses` with `tools:[{type:"web_search"}]` succeeded

## Data Flow Trace

`mapResponsesRequest()` currently does this:

1. resolve the alias or exact-model pool through `resolveRequestedModelPool()`
2. apply endpoint override if requested
3. optionally apply difficulty routing
4. optionally apply controller routing
5. forward hosted tools into `executionRequest.tools`

The missing step is a hosted-tool compatibility filter between pool resolution and routing.

The current code only treats hosted `responses` tools as:

- `needsTools: true`
- execution payload entries with `kind: "hosted"`

That is not enough, because the route planner does not know that hosted `responses` tools currently require an OpenAI Codex Subscription GPT-5.3+ endpoint in this runtime.

By contrast, `/role-model-router/packages/provider-openai/src/index.ts` already encodes the transport truth:

- hosted OpenAI tools are only supported on the Responses API path
- OpenAI Codex Subscription exact execution preserves those hosted tools correctly

So the bug is not in the provider adapter. The bug is in runtime-host-bridge candidate eligibility before a routed request is executed.

## Root Cause Summary

The runtime-host bridge lacks request-surface-aware endpoint filtering for hosted `responses` tools.

As a result:

1. alias/controller routing keeps non-supporting endpoints in the candidate pool for hosted `web_search`
2. routed selection can choose a provider that does not support that hosted tool surface
3. the failure appears later as a provider-side `404` instead of being prevented during routing

## Fix Strategy

1. add RED regressions for hosted `responses` tool routing
2. filter routed `responses` candidates when hosted tools are requested
3. restrict that hosted-tool slice to supported OpenAI Codex Subscription GPT-5.3+ models for now
4. verify exact GPT hosted-tool execution still works, exact non-supporting models fail honestly, and alias/controller hosted-tool requests now land on the OpenAI endpoint
